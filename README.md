Kalinga Trails Website

About the Website
Kalinga Trails is a website for a hiking and outdoor adventure business. It provides visitors with information about hiking trails, activities, guides, and the services offered by the business. The website is designed to help visitors explore hiking options and contact the business for inquiries.
Website Pages

The website contains the following pages:
- Home – Introduces Kalinga Trails and highlights its hiking and outdoor activities.
- About Us – Provides information about the business.
- Trails & Hikes – Shows the available hiking trails and their details.
- Hike Details – Presents more information about a selected hike.
- Community – Shares hiking activities and community-related content.
- Gallery – Displays photos of trails, mountains, and hiking experiences.
- Contact Us – Provides contact information and an inquiry form.

Technologies Used
- HTML5 – Used to create the structure and content of the website.
- CSS3 – Used for the website's design, layout, colors, and responsive styling.
This version uses HTML and CSS only. JavaScript and database functions are not yet included.

Design Features
- Nature-inspired colors based on forests, mountains, and outdoor adventures.
- Responsive layout for desktop and mobile screens.
- Dropdown navigation menu to save space.
- Gradient backgrounds and glassmorphism effects.
- Hover effects using transitions and transforms.
- Box shadows to add depth to selected sections and content.
- Footer links for Facebook, Instagram, and Viber.
